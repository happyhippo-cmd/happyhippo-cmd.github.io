Cover Letter

자기소개서

지원 동기

저는 AI가 실제 현장의 일하는 방식을 바꾸는 AX 분야에서 경험을 쌓고 싶어 라이넨스에 지원했습니다. 물류 스타트업 CX로 3년 7개월 일하며, 반복되는 문의의 원인을 찾아 시스템으로 바꾸면 사람이 같은 일을 덜 하고 서비스 품질에 더 집중할 수 있다는 것을 직접 경험했습니다.

라이넨스의 AX Engineer는 책상 위가 아니라 공장 현장에서 문제를 찾고, 만든 결과물이 실제로 쓰일 때까지 책임지는 자리라는 점에서 제가 해 온 일과 가장 가깝다고 느꼈습니다.

현장 문제를 정의하고 숫자로 해결한 경험

이전 회사에서는 회사가 빠르게 성장하면서 같은 인원으로 늘어나는 문의를 감당해야 했습니다. 저는 반복되는 문의를 목록으로 정리하고, 문의량과 개발 난이도를 기준으로 우선순위를 정해 매달 1~2개씩 개선안을 제안했습니다. 그 결과 10~20건의 기능 개선으로 이어졌습니다.

대표적으로 월 30~40건, 매달 15~20시간이 들던 영수증 요청 문의는 원인을 "고객이 앱에서 직접 받을 수 없어서"로 정의하고 다운로드 기능을 제안해 0건으로 줄였습니다. 하루 30~40건이던 배송 일정 문의는 카카오톡 사전 안내로 약 절반으로 줄였습니다. 또 문의 데이터를 매주 MD팀과 물류센터에 공유해 거래처 교체와 입고 검수 강화로 이어지게 했습니다.

물류센터에 직접 가서 상품이 입고되고 출고되는 과정을 보기도 했습니다. 고객 문의 뒤에는 항상 현장의 흐름이 있다는 것을 알게 되었습니다.

AI로 직접 만들어 본 경험

SK네트웍스 Family AI 캠프 최종 프로젝트 K-Dive에서 5인 팀으로 외국인 관광객용 K-컬처 추천 서비스를 만들었습니다. 저는 전시·팝업 데이터 수집과 검색 기능을 맡아 PostgreSQL 저장·조회, FastAPI, Docker를 사용했고, 저장 전 데이터 검증과 Discord 장애 알림을 구성했습니다.

서비스에는 OpenAI API를 활용한 요약·번역, LangGraph 추천 에이전트, Airflow 매일 자동 실행, AWS EC2 배포가 들어갔습니다. 이 과정에서 AI 코딩 도구를 활용해 짧은 기간에 작동하는 결과물을 만들고, 문제가 보이면 바로 고치는 방식에 익숙해졌습니다.

입사 후 포부

처음에는 공장장님과 작업자분들 옆에서 업무 흐름을 배우고, 작은 불편 하나라도 빠르게 도구로 만들어 실제로 쓰이게 하겠습니다.

운전이 가능해 여러 공장을 오가는 일에도 어려움이 없습니다. 한 공장에서 만든 개선이 다른 공장에도 쓰일 수 있도록 정리하는 것까지 책임지는 AX Engineer가 되겠습니다.
